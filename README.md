# Rick and Morty API App

Aplicativo desenvolvido como parte das atividades do **Kobe Start**, com o objetivo de consolidar conhecimentos em **Flutter** e **Dart**.  
O projeto utiliza a versão **REST** da [Rick and Morty API](https://rickandmortyapi.com/) para consumir e exibir informações sobre personagens.

---

## 🎯 Objetivo
O objetivo foi criar uma aplicação funcional, utilizando os aprendizados adquiridos no **workshop de Flutter**.

---

## 📱 Funcionalidades

### **Home Page**
- Exibe uma lista com os **20 primeiros personagens**.
- Mostra **nome** e **imagem** de cada personagem.

### **Details Page**
- Ao selecionar um personagem, são apresentados:
  - Nome
  - Imagem
  - Status
  - Espécie
  - Última localização
  - Primeira aparição
